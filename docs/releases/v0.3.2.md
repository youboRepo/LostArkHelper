修复部分官方活动链接无法导入的问题，并提供更新 token 后恢复待确认任务的流程。

- 四端导入均兼容参数名大小写，支持师徒结伴链接中的 `accType=qc`。token、access token 等参数值保持原样；不同大小写的重复同名参数仍拒绝导入。
- 服务器、Windows、Linux 遇到提交结果未确认时，提示前往账号管理更新 token。成功保存同一游戏账号、同一角色的凭据后，解除该账号的待确认限制。
- 无效链接、身份不匹配或凭据保存失败时保留原待确认记录；不会清除其他账号的数据。
- 更新 token 本身不触发签到或领奖。下一次手动或定时执行先重新查询官方状态，跳过已签到和已领取项目。如果新一次提交仍失败或结果未知，再次保留待确认记录并提示更新。
- 待确认提示不表示已确定 token 过期；官方接口临时故障仍可能导致执行失败。

Windows/Linux v0.3.0 起可在“定时设置 → 版本更新”安装。若旧版因待确认记录拒绝更新，请先按旧版流程确认操作状态，或停止服务后手动替换程序文件，保留原数据目录；v0.3.2 启动后即可通过更新 token 解除限制。iPhone 用户需下载并导入新快捷指令，原有保存的链接可继续读取。

验证包括导入解析、参数冲突拒绝、HTTP 导入成功/失败、账号隔离、待确认恢复后重新查询再执行，以及快捷指令动作模拟。自动化验证使用虚构凭据，不请求真实游戏签到或领奖；签名与模拟通过不能替代 iPhone 真机验收。
