补充兼容官方分享链接中的同值重复参数，例如两次出现的 `acctype=qc`。

- 服务器、Windows、Linux 和 iPhone 均接受同名、同值的重复参数，并保留 v0.3.2 的参数名大小写兼容。
- 同名参数的值冲突（如 `accType=qc&acctype=wx`）仍拒绝导入；token 等凭据值保持大小写原样。
- 保留更新 token 后解除待确认任务限制的流程：只在同一账号、同一角色的凭据成功保存后清除该账号的待确认记录；下次执行先重新查询官方状态。
- 新增相同值重复、多次重复、不同大小写参数名、冲突值、空值及 HTTP 导入恢复回归测试。测试使用虚构凭据，不提交真实签到或领奖。
